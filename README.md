# Minecraft Texture Skin: Aurora Vancuper

Aurora Vancuper is a pixel-art Minecraft texture and character skin featuring a light complexion, white hair with brown streaks in a ponytail, mismatched dark-red and light-blue eyes, blue ice scars, a black face mask, a dark winter coat, a blue ice-flake emblem, and dark pants with white knee details.

## Install

1. Download `assets/textures/aurora_vancuper.svg`.
2. Render or export the SVG as a 64x64 PNG.
3. Preserve crisp pixel edges and transparency when exporting.
4. Open Minecraft's skin customization or skin upload screen.
5. Select the exported PNG and choose the matching player model supported by your Minecraft edition.

## Use

1. Equip the Aurora Vancuper skin in Minecraft.
2. Use the skin in single-player worlds, multiplayer servers, screenshots, or character-themed builds.
3. Keep the exported image at 64x64 pixels so the Minecraft skin layout remains aligned.
4. If your editor scales the SVG, use nearest-neighbor or pixel-art scaling to keep the texture sharp.
